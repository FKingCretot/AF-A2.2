5 · Grammaire · Édito p. 61

Chaque ou tout ?

Chaque = each, every

chaque + nom

Il ne change jamais : pas de -e, pas de -s.
Le nom est toujours au singulier.

  • chaque jour every day
  • chaque semaine every week
  • chaque personne each person

Tout = all, every

tout + le / la / les + nom

Il change comme le nom : masculin, féminin, pluriel.

  • tout le monde everybody
  • toute la journée all day
  • tous les jours every day
  • toutes les qualités all the qualities

💡 Même sens : chaque jour = tous les jours every day · chaque semaine = toutes les semaines every week
